**REQUIREMENTS**:
Python 3.10.11, 3.14, or 3.14.5
--------------------------------------
**How the game works:**
The game uses Python's *random* Library to randomly select colors and you, yes, YOU can predict the next color that comes up! If it lands on Red, You lose, and if you predict the next color correctly, it tells you that you did a good job! Try not to land on Red, I guess!
