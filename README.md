**How the game works:**
The game runs on Python, as seen in the requirements section. It uses the Random Library to randomly select colors and you, yes, YOU can predict the next color that comes up! If it lands on Red, You lose, and if you predict the next color correctly, it tells you that you did a good job! Try not to land on Red, I guess!
